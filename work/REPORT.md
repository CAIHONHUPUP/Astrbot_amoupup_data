## 3. P0 / P1 / P2

### P0（数据安全 / 崩溃）：无
评估全程只读真实库，sha256 未变；recall 写回只落在一次性副本。

### P1-1 证据词构造把精确命中拆碎 → 整条空召回（已修）

`_informative_terms` 原来「先删虚词、再配对」：`迟到罚了多少钱` → 删掉「到」→ `迟|罚|钱` → 二元组 `迟罚 / 罚钱`，
真实记忆「…（迟到罚款）…」里没有这两个组合 → 关键词闸整条挡掉 → **空召回**。

- q18「迟到罚了多少钱」：before 0 条 → current 6 条，precision 0 → 0.67
- q06「我让你记住的那两个字是什么」：before 0 条 → current 6 条（命中真实记忆 790「记住『大米』」）
- 旧实现还有反方向的噪声：`我想学钢琴` → `我想` 这种「代词+字」也被当证据

修法（`utils/text_process.py`）：按**原始字序**配对（保邻接），只丢两类——两个字都是虚词的（了吗/多少）、
含纯连接词/代词的（我想/的新/听吗，新增 `GLUE_CHARS`）。`迟到 / 记住 / 个月` 全部保留，
`我想 / 的新 / 听吗 / 晚谁` 全部挡掉。**没有改权重、阈值、运算顺序，也没有改召回四段结构。**

A/B 契约（`tests/contracts/recall_golden.json`，11 个场景）：10 个场景逐字节不变；
只有 `long_query` 场景分数变化 ≤0.0249，id / 顺序 / 条数完全一致 → 已按有意变更重生成该 golden，
并在 REPORT 记录（这是唯一一处契约变化）。

### P1-2 注入去重阈值 0.75 太松 → 同一件事一起注入（已修）

before 臂里 2.0% 的注入条目有近重复搭档（二元组 Jaccard ≥ 0.6）：q03 0.66、q41 0.62、q43 0.62、q60 0.61。
`diversify_ratio` 在面板里没有入口、默认 0.75，比这些值都高。

修法：`DEFAULT_SETTINGS["diversify_ratio"]` 0.75 → 0.60（`near_duplicate_ratio` 是**写库时**的阈值，
仍保持 0.92 不动）。实测近重复注入 2.0% → 0%，命中率不变（0.926），p@6 不变（0.412）。
q03 的 p@6 从 1.00 掉到 0.83 是「两条一样的 ID 记忆被合并成一条」的固定分母效应，不是质量下降。

### P1-3 注入字数偏大（只给数字，未改代码）

平均 1278 字；单条查询最高 4201 字（q49，6 条记忆合计）、3805 字（q20）——长 `conversation_summary` / `daily_digest` 是主因。
按「每条最多 120 字」渲染后平均 545 字（−57%），命中与排序不受影响。
**渲染在 amo 侧（本仓库没有注入渲染代码）**，所以没有在这里改实现，只提供参考实现与数字：
`work/recall_common.render_injection()`（`item_max=120`，超长加省略号）。

### P2（未修，附原因）

1. **数字夹在中文里打断二元组**：`11月6号` → `月6号` 不是 `月号`，q10 仍 0 命中。要修得把数字并进字流，
   影响面比 P1-1 大，本次不动。
2. **范围时间没解析**：「最近三天」只被当关键词（`最近/三天`），q40 仍 0 命中且返回 3 条 finance 流水。
   现有时间解析只覆盖 昨天/前天/上周X/具体日期；要做需要扩展 `_parse_time_span` 并与 `recall_messages` 联动。
3. **单字/寒暄仍会命中 6 条**：q61「好」、q66「睡了吗」、q60「哈哈哈」——无答案正确弃权率只有 0.25。
   这是 `min_matched_terms=1` 的既有设计（为了 1~2 字短查询能召回「牛杂/火锅」），
   收紧会牺牲短查询召回，本次不动；建议 amo 侧对「无信息量短消息」直接不调 recall。
4. **语义闸 0.82 实测不可达**：抽样候选余弦只有 0.49~0.57，`vec_pass`（要求 ≥0.82 且领先 0.08）
   永远为假 → 纯语义永不单独放行，语义只做加权。效果：MRR 0.824 → 0.850（+0.026），p@6 不变，
   代价 +150ms/查询。要真正启用语义需重新标定阈值（建议 ~0.55 + margin），但会放大噪声，本次不动。
5. **财务聚合问题**（「我这个月花了多少钱」）不属于记忆召回，返回的是对话摘要；应由 stats/财务表回答。
6. **尾部截断实验否决**：按「分数 < 0.5×top 不注入」实测几乎无效（注入 1389→1382 字，p@6 0.412→0.412），
   因为分数分布很平（top≈0.8 vs 尾≈0.6）；阈值抬到 0.75 会削掉相关记忆，故不采用。
7. **朴素子串基线全崩**（命中 0.037 / 空召回 95.5%）：自然问句几乎不可能整句出现在记忆里，
   这组数字只用来证明「现有管线不是可有可无的」。
